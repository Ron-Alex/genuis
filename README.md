# Genuis

An adaptive banking workspace built with Next.js, Capital One Nessie, and NVIDIA Nemotron.

See [GETTING_STARTED.md](./GETTING_STARTED.md) for setup, environment variables, architecture, workflows, and prototype limits.

Quick start: add keys to `.env` using `.env.example`, then run `npm run dev`. Without keys, the app runs in explicitly labeled demo mode.

Verification: `npm test` and `npm run build`.
